# Tabeth Cinderella Matongo — Portfolio

A responsive, cosmic-themed portfolio website inspired by the structure and visual direction of `adv-aith.dev`, adapted for Tabeth Cinderella Matongo's AI governance and SDG-16 focus.

## Run locally

```bash
npm start
```

Then open <http://localhost:4173>.

## Build

```bash
npm run build
```

The build script copies the static site into `dist/`.
